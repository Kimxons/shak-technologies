## Performance Metrics

### Expected Performance (No Change)

| Metric | Value | Notes |
|--------|-------|-------|
| **Cache Hit** | < 1ms | Data served from memory |
| **Cache Miss (First Request)** | 100-300ms | API call + DB query |
| **Cache Duration** | 4 hours | SystemCodesPolicy |
| **Parallel Requests** | ~150-400ms | Multiple codes loaded simultaneously |
| **Cache Size** | ~2-10 KB | Per system code (compressed) |
| **Memory Usage** | Minimal | Shared across all users |

### Network Traffic
```
WITHOUT CACHE (Every Request):
  - 28 system codes × 100-300ms = 2.8-8.4 seconds total
  - Heavy database load
  - High API traffic

WITH CACHE (After First Request):
  - 28 system codes × < 1ms = < 28ms total ?
  - Zero database load
  - Zero API traffic
  - 4-hour cache lifespan
```

## Database Query

### Stored Procedure: p_v1_GetSystemCodes

**Input:**
```json
{
  "CodeID": "TitleID"
}
```

**SQL Query (Typical):**
```sql
SELECT 
    CodeID,
    SubCodeID,
CodeDescription,
    DisplayOrder,
    ParentCodeID,
    isActive,
    isDeleted
FROM t_SystemCodeDetail
WHERE CodeID = @CodeID
  AND isDeleted = 0
  AND isActive = 1
ORDER BY DisplayOrder ASC, SubCodeID ASC
```

## Complete Request Flow Example

### Scenario: Loading Personal Tab Dropdowns

```
1. USER: Opens Client Maintenance ? Personal Tab
   ?
   ?
2. CONTROLLER: ClientPersonalController.Index()
   ?
   ? Calls: _apiCachedService.GetMultipleDropdownCodeOptionsAsync(
   ?          ["TitleID", "GenderID", "CountryID", ...9 codes])
   ?
   ?
3. API CACHED SERVICE: GetMultipleDropdownCodeOptionsAsync()
   ?
   ? Creates 9 parallel tasks for GetSystemCodeOptionsAsync()
   ?
   ?
4. FOR EACH CODE: GetSystemCodeOptionsAsync("TitleID")
   ?
   ? Checks cache: SYSCODES:TitleID
   ? ?? HIT  ? Return cached List<SystemCodeDetail>
   ? ?? MISS ? Call FetchSystemCodeOptionsFromApi("TitleID")
   ?
   ?
5. FETCH FROM API: FetchSystemCodeOptionsFromApi("TitleID") ? UPDATED
   ?
   ? Builds request: { CodeID: "TitleID" }
   ? Calls: ApiEndpoints.GET_SYSTEM_CODES ? NEW ENDPOINT
   ? Sends: POST to api/v1/Shared/GetSystemCode
   ?
   ?
6. API SERVICE: CreateAsync()
   ?
   ? Resolves URL: https://systemcore-api/api/v1/Shared/GetSystemCode
   ? Adds auth headers
   ? Sends HTTP POST
   ?
   ?
7. SYSTEMCORE API: SharedController.GetSystemCode()
   ?
   ? Validates request
   ? Calls: _repo.GetSystemCodes(requestJson)
   ?
   ?
8. REPOSITORY: SharedRepo.GetSystemCodes()
   ?
   ? Executes SQL: EXECUTE p_v1_GetSystemCodes @RequestData={...}
   ?
   ?
9. DATABASE: p_v1_GetSystemCodes
   ?
   ? Queries: t_SystemCodeDetail
   ? Returns: JSON with system code details
   ?
   ?
10. RESPONSE BUBBLES BACK UP:
  Database ? Repository ? Controller ? HTTP Response ? ApiService
      ? ApiCachedService ? CACHE (stores for 4 hours)
? Transform to DropdownCodeItem ? Controller ? ViewData
  ? View renders dropdown
```

**First Request**: ~150-300ms (API + DB)  
**Subsequent Requests**: < 1ms (Cache hit)
